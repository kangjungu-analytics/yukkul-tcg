# 유꿀 TCG

포켓몬·원피스 카드를 네이버에서 검색하고, 직접 확인한 가격을 적어두는 무료 사이트입니다. 단정한 카드샵 느낌의 화면에 작은 돼지 마스코트를 더했습니다.

## 1단계: 내 컴퓨터에서 열기

1. `index.html`, `style.css`, `script.js` 세 파일이 같은 폴더에 있는지 확인합니다.
2. `index.html`을 더블 클릭합니다.
3. 포켓몬 또는 원피스를 고르고 카드 이름이나 번호를 입력한 다음 **네이버에서 카드 찾기**를 누릅니다.
4. 네이버 검색 화면을 사이트 안에서 확인하고, 찾은 가격을 아래에 기록합니다. 네이버가 화면 안 표시를 막으면 오른쪽의 새 창 링크를 이용합니다.

프로그램 설치, 계정, API 키가 필요하지 않습니다.

## 파일 세 개가 하는 일

- `index.html`: 제목, 설명, 입력칸과 버튼을 배치합니다.
- `style.css`: 색, 글자, 여백처럼 화면에 보이는 부분을 꾸밉니다.
- `script.js`: 게임 선택, 네이버 검색어 만들기, 가격 기록 저장을 작동시킵니다.

## 가격은 직접 확인합니다

유꿀 TCG는 카드 가격을 자동으로 수집하거나 최저가를 계산하지 않습니다. 네이버 검색 화면에서 카드 버전·상태·판매 완료 여부를 확인한 뒤, 가격을 직접 기록합니다. 관심 카드와 가격 기록은 이 브라우저에만 저장되고 다른 기기와 공유되지 않습니다. 네이버의 검색·쇼핑 API 정책에 따라 제공 방식이 바뀔 수 있습니다.
